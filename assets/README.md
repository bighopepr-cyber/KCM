# KCM Assets

Static assets including logos, icons, and images for documentation and branding.

## Contents

| File | Purpose | Format |
|------|---------|--------|
| logo.svg | KCM logo (primary) | SVG |
| icon.svg | KCM icon (favicon) | SVG |
| banner.svg | Repository banner | SVG |

## Usage

Assets are used in:
- README.md header
- Website (website/)
- Documentation (docs/)
- GitHub repository

## Guidelines

- Use SVG format for scalability
- Maintain consistent color palette (blue theme)
- Keep file sizes under 50KB
- Provide @2x versions for retina displays
