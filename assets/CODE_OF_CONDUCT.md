# assets/ Community Guidelines

> For project-wide community guidelines, refer to the [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) located in the repository root.

## Respect

All contributors to the KCM assets must treat each other with respect:

- Value visual design perspectives and branding expertise
- Accept feedback on asset quality gracefully
- Acknowledge the effort required for high-quality visual assets
- Consider accessibility requirements for all assets

## Professional Communication

- Explain design decisions clearly when proposing assets
- Reference brand guidelines when suggesting color or style changes
- Provide context for why an asset is needed
- Use precise terminology for visual design concepts

## Code Review Etiquette

When reviewing asset changes:

- Focus on visual quality, consistency, and purpose
- Suggest improvements rather than demanding changes
- Acknowledge well-crafted assets
- Consider accessibility in feedback
- Verify rendering across different contexts

## Collaboration

- Share design rationale through documentation
- Maintain consistency with existing assets
- Update README.md when adding new assets
- Coordinate with documentation team for integration
- Consider cross-platform rendering requirements

## Reporting Issues

Asset issues should be reported via:

- **Visual bugs**: Issue with screenshot and expected behavior
- **Inconsistencies**: Issue describing deviation from brand guidelines
- **Missing assets**: Issue with use case and priority
- **Security concerns**: Direct message to security team, not public issue

## Enforcement

Asset quality standards are enforced through:

| Mechanism | Scope |
|-----------|-------|
| Code review | All asset changes require maintainer approval |
| File size limits | CI enforces <50KB limit |
| SVG safety | CI scans for executable code |
| Visual review | Manual verification before merge |

Violations may result in:

1. Request for revision
2. Discussion in PR review
3. Escalation to Engineering Orchestrator
4. Revert of merged changes if standards were not met
