Getting Started

Prerequisites

  • Rust 1.75+ (stable)
  • Linux x86_64 (primary target)
  • macOS / Windows (community supported)

Install

git clone https://github.com/knowledge-columnar/kcm
cd kcm
cargo build --release

Run Tests

cargo test --workspace

Contribution Guide

Development Workflow

  1. Fork the repository
  2. Create a feature branch: git checkout -b feature/my-change
  3. Make changes following rules in Engineering Rules
  4. Add tests for all new functionality
  5. Run cargo test --workspace -- all must pass
  6. Run cargo clippy --workspace --all-targets -- -D warnings
  7. Run cargo fmt --all
  8. Submit pull request

Code Standards

  • All public APIs return Result<T, KcmError>
  • No unwrap() in production code paths
  • No panic!() in production code
  • No TODO/FIXME/HACK comments
  • No placeholder implementations
  • Every unsafe block must have SAFETY comment
  • Zero clippy warnings enforced
