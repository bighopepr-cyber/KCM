# .agents/ Community Guidelines

> For project-wide community guidelines, refer to the [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) located in the repository root.

## Respect

All contributors and AI agent systems interacting with the `.agents/` directory must:

- Treat all community members with dignity and respect
- Value diverse perspectives and experiences
- Be considerate in language and behavior
- Respect different opinions and approaches to governance

## Professional Communication

- Use clear, concise, and professional language in all communications
- Provide constructive feedback rather than criticism
- Acknowledge the work of others
- Ask clarifying questions when requirements are ambiguous
- Document decisions and their rationale

## Code Review Etiquette

When reviewing changes to `.agents/` files:

- Focus on the content and its correctness, not the author
- Provide specific, actionable feedback
- Acknowledge improvements and positive changes
- Be open to alternative approaches
- Ensure consistency with `skills/` directory structure

## Collaboration

- Work together to maintain structural consistency between `.agents/skills/` and `skills/`
- Share knowledge about AI agent governance best practices
- Help new contributors understand the `.agents/` directory purpose and structure
- Coordinate changes that affect multiple skill definitions

## Reporting Issues

If you identify issues with `.agents/` content:

1. Create a detailed issue describing the problem
2. Include the specific file and section affected
3. Provide evidence of the inconsistency or error
4. Suggest a fix if possible

## Enforcement

Violations of these community guidelines may result in:

- Request for revision of the contribution
- Temporary suspension of contribution privileges
- Removal from the project for repeated or severe violations
