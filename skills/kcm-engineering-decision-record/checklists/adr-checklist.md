# ADR Checklist

## Decision Documentation
- [ ] Context clearly described
- [ ] Decision clearly stated
- [ ] Rationale explained
- [ ] Alternatives considered
- [ ] Consequences documented

## Quality
- [ ] ADR number assigned
- [ ] Status set (Proposed/Accepted/Deprecated)
- [ ] Date recorded
- [ ] SSOT references included
- [ ] No duplicate ADRs

## Completeness
- [ ] Positive consequences listed
- [ ] Negative consequences listed
- [ ] Neutral consequences listed
- [ ] Rejected alternatives explained
