# kcm-change-impact-analysis

> Priority: P3 | Authority: Block | Scope: Change impact, ripple effects, compatibility

## Overview

Senior architect analyzing the impact of proposed changes across the entire system.

## Purpose

Analyze dependencies, assess compatibility, identify affected modules, evaluate risks, and generate impact matrices.
