# scripts/ Community Guidelines

> For project-wide community guidelines, refer to the [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md) located in the repository root.

## Respect

All contributors must treat others with respect. This includes尊重 differing viewpoints, experience levels, and backgrounds. Harassment, discrimination, and personal attacks are not tolerated.

## Professional Communication

- Use clear, concise, and professional language in code reviews, issues, and discussions.
- Provide constructive feedback — focus on the code, not the person.
- Acknowledge contributions and effort, even when requesting changes.

## Code Review Etiquette

- Review code objectively based on technical merit and project standards.
- Suggest improvements with rationale; do not demand changes without explanation.
- Respond to review feedback promptly and constructively.
- Approve reviews only when all concerns are addressed.

## Collaboration

- Share knowledge openly — document decisions and rationale.
- Help new contributors understand the codebase and contribution process.
- Coordinate changes that affect multiple components to avoid conflicts.

## Reporting Issues

- Report security vulnerabilities privately via the process described in [SECURITY.md](../SECURITY.md).
- Report bugs and feature requests through the project's issue tracker.
- Include sufficient detail to reproduce and diagnose the issue.

## Enforcement

Violations of these guidelines may result in:

1. A private warning from maintainers.
2. Temporary suspension of contribution privileges.
3. Permanent removal from the project for severe or repeated violations.

Enforcement decisions are made by project maintainers in accordance with the repository [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md).
