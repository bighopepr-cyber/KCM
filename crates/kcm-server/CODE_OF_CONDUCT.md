# kcm-server Community Guidelines

> For project-wide community guidelines, see the root `CODE_OF_CONDUCT.md`.

## Respect

All participants in kcm-server development must treat each other with respect. This includes:

- Acknowledging diverse perspectives and experience levels
- Providing constructive feedback rather than personal criticism
- Being patient with questions from new contributors
- Recognizing that technical disagreements are opportunities for learning

## Professional Communication

- Use clear, concise, and technical language in issues, PRs, and code review
- Avoid sarcasm, condescension, or dismissive tone
- Back technical claims with evidence, benchmarks, or specification references
- Disagree with ideas, not people
- Keep discussions focused on the technical topic at hand

## Code Review Etiquette

- Review code, not the author
- Provide specific, actionable feedback with line references
- Distinguish between blocking issues and suggestions
- Acknowledge good work and improvements
- Respond to review feedback promptly and professionally
- Use the SSOT documents as the authoritative reference for correctness disputes

## Collaboration

- Share knowledge freely through documentation and code comments
- Mentor new contributors when possible
- Credit others for their contributions
- Collaborate on solutions rather than competing for credit
- Follow the established engineering gates and skill governance process

## Reporting Issues

- Report security vulnerabilities privately via the security policy in root `SECURITY.md`
- Report bugs with reproduction steps and environment details
- Report code of conduct violations to the project maintainers
- All reports will be handled confidentially and without retaliation

## Enforcement

Violations of these guidelines may result in:

1. A private request to modify behavior
2. A formal warning
3. Temporary or permanent removal from the project

The severity of enforcement depends on the nature and frequency of the violation. The project maintainers reserve the right to take immediate action in cases of harassment, discrimination, or other serious misconduct.
