# Orchestrator Engines

Core engine components of the KCM Engineering Orchestrator.

## Engines

| Engine | File | Purpose |
|--------|------|---------|
| Skill Router | routing.md | Selects skills based on change type |
| Execution Engine | execution-engine.md | Executes engineering workflow |
| Planning Engine | planning-engine.md | Creates execution plans |
| Approval Engine | approval-engine.md | Manages approval chains |
| Conflict Engine | conflict-engine.md | Resolves skill conflicts |
| Escalation Engine | escalation-engine.md | Handles escalations |
| Quality Engine | quality-engine.md | Enforces quality gates |
| Reporting Engine | reporting-engine.md | Generates reports |
| State Machine | state-machine.md | Manages task states |
