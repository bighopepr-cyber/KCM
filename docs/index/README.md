# Documentation Index

Auto-generated navigation index for all KCM documentation.

## Regenerating the Index

```bash
bash tools/doc-generator/generate-index.sh
```

## Index Files

| File | Description |
|------|-------------|
| `docs/INDEX.md` | Main documentation navigation index |
| `docs/search-index.json` | Search index for documentation search |
