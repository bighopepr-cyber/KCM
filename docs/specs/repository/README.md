# Repository Specifications

**Document ID:** KCM-REPO-README-001
**Version:** 2.0.0
**Status:** Active
**Owner:** Engineering Orchestrator (P1)

This directory contains the engineering and repository-level contract documents that govern repository organization, build discipline, and maintenance policy. These documents are reference material for maintainers and contributors and define the repository contract surface without duplicating the primary PRD set.

## Canonical Documents

| Document | Purpose |
|----------|---------|
| REPOSITORY_ARCHITECTURE.md | Overall repository architecture and ownership model |
| WORKSPACE_LAYOUT.md | Cargo workspace configuration |
| FOLDER_CONVENTION.md | Directory structure and ownership |
| NAMING_CONVENTION.md | Naming rules for all artifacts |
| CRATE_OWNERSHIP.md | Crate responsibilities and maintainership |
| DOCUMENTATION_STRUCTURE.md | Documentation hierarchy and authority model |
| VERSIONING_POLICY.md | Semantic versioning and compatibility |
| DEPENDENCY_POLICY.md | Dependency management and auditing |
| RELEASE_POLICY.md | Release process and changelog |
| REPOSITORY_GOVERNANCE.md | Decision-making and PR review |

## Authoritative Scope

The repository specification set is intentionally limited to current engineering contracts. Historical or retrospective material belongs in the archive/report set rather than in the canonical specification index.
