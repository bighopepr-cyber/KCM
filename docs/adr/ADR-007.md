# ADR-007: parking_lot for Synchronization

## Status
Accepted

## Context
KCM needs thread-safe synchronization primitives (Mutex, RwLock). Options:
- std::sync: Standard library, correct but slow
- parking_lot: Faster, same API
- crossbeam: More features, different API

## Decision
Use parking_lot for all synchronization primitives.

## Consequences

### Positive
- 3-5x faster than std::sync
- Same API as std::sync (easy migration)
- No poisoning (simpler error handling)
- Used by 7 crates in the workspace

### Negative
- External dependency (but widely used, stable)

## Alternatives Considered

| Alternative | Pros | Cons | Decision |
|------------|------|------|----------|
| std::sync | No dependency | Slower (3-5x) | Rejected |
| crossbeam | More features | Different API | Rejected |
| **parking_lot (chosen)** | Fastest, same API | External dep | **Accepted** |
