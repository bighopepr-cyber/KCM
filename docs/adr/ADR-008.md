# ADR-008: Criterion for Benchmarking

**Document ID:** ADR-008
**Version:** 1.0.0
**Status:** Accepted
**Author:** KCM Engineering Team
**Date:** 2026-08-04
**Deciders:** Architecture Guardian (P5)

## Context
KCM needs a benchmarking framework for performance regression detection. Options:
- criterion: Statistical analysis, HTML reports
- test::Bencher: Nightly-only, no statistics
- custom: Full control, high effort

## Decision
Use criterion for all benchmarks.

## Consequences

### Positive
- Statistical analysis (regression detection)
- HTML reports with visualization
- Stable Rust compatible
- Baseline comparison

### Negative
- Slower than raw test::Bencher
- Additional dependency

## Alternatives Considered

| Alternative | Pros | Cons | Decision |
|------------|------|------|----------|
| test::Bencher | Fast, built-in | Nightly-only, no stats | Rejected |
| custom | Full control | High effort | Rejected |
| **criterion (chosen)** | Statistical, stable | Slower | **Accepted** |
