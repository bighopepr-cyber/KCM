# KCM Rust Examples

Working examples demonstrating KCM usage in Rust.

## Examples

| Example | Description |
|---------|-------------|
| basic_usage | Create database, insert facts, query |
| transactions | Transaction management (commit/rollback) |
| reasoning | Define rules and run inference |

## Running Examples

```bash
# Basic usage
cargo run --example basic_usage

# Transactions
cargo run --example transactions

# Reasoning
cargo run --example reasoning
```

## Prerequisites

- Rust 1.85+
- KCM workspace built
