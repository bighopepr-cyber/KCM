# kcm-docs

Documentation generator for KCM.

## Status: Planned

## Commands

| Command | Description |
|---------|-------------|
| kcm-docs generate <db> | Generate API docs |
| kcm-docs schema <db> | Generate schema docs |
| kcm-docs serve <path> | Serve docs locally |

## Usage

```bash
# Generate documentation
kcm-docs generate my_knowledge.db

# Serve locally
kcm-docs serve docs/
```
