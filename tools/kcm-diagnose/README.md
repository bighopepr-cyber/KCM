# kcm-diagnose

Diagnostics tool for KCM.

## Status: Planned

## Commands

| Command | Description |
|---------|-------------|
| kcm-diagnose run <db> | Run full diagnostics |
| kcm-diagnose performance <db> | Performance diagnostics |
| kcm-diagnose storage <db> | Storage diagnostics |
| kcm-diagnose memory <db> | Memory diagnostics |

## Usage

```bash
# Run full diagnostics
kcm-diagnose run my_knowledge.db
```
