# doc-generator

Documentation generation tools for the KCM repository.

## Tools

### generate-index.sh

Auto-generates `docs/INDEX.md` with navigation to all documentation.

```bash
bash tools/doc-generator/generate-index.sh
```

### generate-search-index.sh

Generates `docs/search-index.json` for documentation search.

```bash
bash tools/doc-generator/generate-search-index.sh
```

## Output Files

| File | Description |
|------|-------------|
| `docs/INDEX.md` | Auto-generated documentation index |
| `docs/search-index.json` | Search index for documentation |
